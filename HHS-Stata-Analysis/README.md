# Household Hunger Scale (HHS) – Stata Analysis

This repository contains Stata code for computing and analyzing
the Household Hunger Scale (HHS).

## Author
Muhiyadin Aden

## Folder structure
- data/    : input data
- do/      : Stata do-files
- results/ : outputs and logs

## Software
Stata 15+

## How to run
1. Open Stata
2. Set working directory to project folder
3. Run:
   do do/HHS_analysis.do
